Instructions
  1. Set a time target, then use the remaining-time countdown to track progress against the day.
  2. Add named activities for groups of work, then use Add task inside each activity. Edit activities from their priority controls.
  3. Start one task at a time. Starting another task pauses the active timer and moves the task to the left of its activity.
  4. Use Urgent on a task tile to add a red border and show the urgent flag below the activity totals.
  5. Use the priority arrows to rearrange activities vertically, or drag task boxes within and across activities.
  6. Open Time log to add, edit, or nudge entries. Generate reports, or use Export and Import to move the full board between browsers.
  7. Timekeeper stores data in this browser. Deleting cookies and site data for this site deletes all details, so it is best to run it on a side computer or export backups before clearing site data.
