Instructions
  1. Set a time goal, then use the remaining-time countdown to track progress against the day.
  2. Add named rows for groups of work, then use Add Task Box inside each row. Rename or delete rows from the row label.
  3. Start one task at a time. Starting another task pauses the active timer and promotes the new task to the top-left priority position.
  4. Use the drag handles to rearrange rows vertically or task boxes within and across rows.
  5. Open Show time log to add, edit, or delete entries. Generate a report for bucket totals, objective totals, and the chronological timeline.
