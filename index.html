Instructions

Timekeeper is a lightweight companion app for tracking work time in a way that supports focus. It helps capture the work, buckets, notes, and time details you can review before entering or discussing them elsewhere.

Get started

  1. Set a daily time target if you want the top dashboard to show remaining time for today.
  2. Add activities for major workstreams, projects, priorities, or outcomes.
  3. Add tasks inside activities. Every task must have a time bucket before it can be started.
  4. Use Start on one task at a time. Starting another task automatically pauses the current timer.
  5. Reprioritize activities with the arrow controls, mark tasks Urgent, and flag notes that should be referenced in standup.
  6. Use Time log to add, edit, or nudge time entries. The top dashboard shows only today's time, while reports can aggregate across multiple days.
  7. Generate an aggregated report when you want to review time by activity, task, bucket, and percentage for weekly or monthly manager conversations.
  8. Download the report when you are ready to reset tracked time. If checked, Delete logs and completed tasks on download clears logs and completed tasks while keeping activities in place.

Data

Data is stored in this browser's local storage and can be exported or imported as JSON. Deleting cookies and site data for this site deletes all details, so it is best to run Timekeeper on a side computer or export backups before clearing site data.

Use Settings to choose a backup folder for browser-approved backups. Timekeeper writes a daily file named like bk-timekeeper-2026-04-30.json, updates that same dated file during the day, and starts a new dated file after midnight. Save backup now writes immediately, and auto-save runs every hour by default while the page is open. If the browser asks for permission again, use Save backup now or choose the backup folder again.

Standup Summary

Instructions

Set the last standup date to show work logged since that standup. Highlighted items, regardless of color, are items you want to talk about among everything available in the summary. Use Hide unhighlighted to narrow the preview and copied summary to highlighted items only. Click bullets in Today to mark yellow focus items, which stay saved across opens and represent work you want to make progress on before the next standup. Notes marked Report in standup appear in Did as purple highlights; removing a purple reported note highlight asks for confirmation and removes Report in standup from that note. Notes flagged for elevation appear in Stuck and are pink the first time they are flagged; changing the pink highlight here does not unflag the note. To unflag a note, use the Flagged Notes pill on the main screen.

What I did since last standup
Tasks with time logged since the selected date, plus Report in standup notes tied to that recent work or created since the selected date, grouped by activity. Reported notes appear as purple highlights; dehighlighting one removes Report in standup from that note after confirmation.
What I'm doing today
Current unfinished tasks, with urgent tasks listed first and the rest in priority order. Highlights here become yellow focus items.
What I'm stuck on
Flagged notes created since the selected date, grouped by activity. New elevation flags start as pink highlights; toggling that highlight only changes whether you plan to talk about it and does not change the note's flagged status.
